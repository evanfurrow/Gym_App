# Gym App

A web application designed to track workouts and fitness goals.

## Live Demo

You can check out the live demo here: [Gym App] (https://evanfurrow.pythonanywhere.com)


## Installation

To run this project locally, follow these steps:
1. Clone the repository: `git clone github.com`
2. Navigate to the directory: `cd gym-app`
3. Open `index.html` in your web browser.
